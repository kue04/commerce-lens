# ADR 0005：经营概览的确定性计算与复用

2026-10-23，已采用。来源为用户确认的本地作品集“经营概览＋分析工作台＋数据概况”方案；本切片仅后端，不调用真实外部模型。

概览请求复用QuerySpec，HTTP1.2.0兼容新增OverviewSchema。昨天对上周同日、7天对前7天、30天对前30天，输入不匹配拒绝而非静默改写。趋势固定截至选择右端的30天，基期按同样偏移逐日配对，每点返回单日QuerySpec。历史窗口可查询，但仍受固定业务时钟和覆盖门禁约束。

AnalyticsService提供有限的日聚合模板（支付/退款分别聚合再union），同一只读repeatable-read事务核查版本、权限、字典和水位，并可执行一个现有分组模板。日期生成与零填充只发生在该指标该日源覆盖通过后；缺失源/分区为null和原因。三指标分别表达可用性，退款缺源不牵连支付/件数。整数、比较、贡献守恒沿用现有实现。

抽取qualityReason供报告查询与概览共用；抽取changeRule保留原报告阈值，报告模板文本不改。变化项最多5条，先总量后真实贡献组；不含“其他”。SKU/渠道/大区的分析入口可精确缩小QuerySpec；类目无筛选字段，保留贡献但不生成范围不符的下钻入口。没有增加QuerySpec字段或模型工具权限。

概览自身不创建run、证据或报告，服务配置为agent也不影响概览固定确定性计算。只有用户进入工作台后才按原会话/run链路执行分析。旧provenance1.0.0/1.1.0与不可变报告可读且不改写。

前端集成前置条件是当前契约/真实样例及后端门禁通过，不依赖真实模型验收。实际页面联调另以浏览器证据验收，不能以Fastify inject代替。
