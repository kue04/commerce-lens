# ADR 0001：本地作品集的数据计算基线

日期：2026-10-22。状态：已采用。需求来源为 docs/PRD.md v1.1 与用户在会话中确认的本地求职作品集目标。

## 范围与冲突决定

1. 使用 TypeScript strict、Pi 1.4.0、Fastify、React、PostgreSQL 18；本轮仅建立 M0/M1 必须的模块，不生成 API/Agent/UI 空实现。前端由用户在 apps/web 独立开发。
2. 用户明确不需要公网，因此原 PRD 的公网认证、TLS、Linux 发布要求不进入当前本地验收。未来开放公网需重新实现并验证这些门槛；本地模型密钥、数据库权限和资源归属仍必须保护。
3. 三个主入口为支付金额、成功退款金额、支付件数；订单数/客单价辅助，净收款内部支持。本轮实现六个底层指标以提前验证跨期退款、去重和非可加边界，不宣称已经完成三类 Agent 场景。
4. 数值精确、安全、证据约束为硬门槛。85% 完成率和 45 秒 P95 为需实测披露的效果目标，不得把 SQL 单次计时作为 Agent 性能结果。

## 本地运行与依赖

系统 Node 为 22.18.0，低于 Pi 1.4.0 engines 要求 >=22.19.0，也不符合 PRD Node 24。scripts/bootstrap-node.ps1 下载校验 SHA256 后在 .tools 内解压 Node 24.22.1，仅修改当前 shell 的 PATH，不修改系统环境。其他平台可自行安装 Node 24 后 npm ci。

未发现系统 PostgreSQL 或 Docker。增加 devDependency embedded-postgres 18.4.0-beta.17：它启动原生 PostgreSQL 18.4 子进程，供开发与集成测试使用，不是内存仿真数据库。包版本含 beta 是该包装器的发布命名；实际服务版本由 SHOW server_version 验证。未调用系统用户创建功能，只监听 127.0.0.1，随机凭证存放忽略目录。正常停止后清理仅本次创建的临时集群；db:start 的持久集群保留。该开发依赖不要求部署时使用，可通过环境变量连接已有 PostgreSQL。

Pi 包和 provider 导入可离线验证；没有 DEEPSEEK_API_KEY 时不调用模型，不寻找机器其他位置的凭证。后续正式配置使用具体模型 ID；模型目录并不证明账号可调用。Fastify/React 在对应阶段或用户前端开发时安装，避免锁定没有当前用途的依赖。

## 数据与查询

- 使用合成数据，固定业务时钟 2026-10-22。90 天、100000 订单、200000 订单行、30 SKU、3 渠道、4 大区；种子通过明细生成订单、退款、星期周期及商品偏好。手工验收小数据独立提供，不当作业务问答固定答案。
- 所有实体键包含 dataset_version + store_id。发布前由数据库验证订单行金额守恒、成功退款金额/件数上限、退款状态与时序；主键和外键保证重复/关联错误无法发布。发布后行级触发器禁止修改，查询绑定不可变版本。
- coverage_start 为新增明确字段，complete_through 采用业务自然日排他边界：2026-10-22 表示完整到 10 月 21 日结束。水位和缺分区强制由 AnalyticsService 核查；模型不能选择跳过。数据集可发布为覆盖不足，用于显式 insufficient_data 场景。
- 使用独立只读数据库登录，非 superuser、非表 owner、无 BYPASSRLS；服务端在只读事务设置版本和店铺 RLS 上下文，提交后自动清除。RLS 设置的值仍必须由服务端已认证上下文提供，不能从用户或模型参数生成授权。
- 查询使用固定标识符映射和参数化值。支付/退款分别聚合后 union，保留退款独有维度，不把退款事件 JOIN 进支付 SUM。每次 SELECT 3 秒超时，分组结果最多读取 403 行用于检测超过 200 个维度键；超限拒绝，不产生截断结论。
- 订单数和 AOV 不做任何可加贡献分解（比仅禁用 SKU 更保守，符合 decompose 的四指标白名单）。AOV 分母为零返回 null；金额和数量所有输入、聚合与差值检查安全整数，溢出拒绝。所有比例保留未舍入值。
- Top-N 按绝对变化降序、字典序打平；有省略分组才补其他。每个维度独立守恒。日期仅支持 2000—2100，上海自然日转换 UTC 边界；本周截至昨天，周一提示无完整日。

## 验证边界

小数据的人工预期与 evals/oracles/aggregate.sql 的独立 SQL 分别核对。SQL oracle 以订单头合计支付、独立退款标量子查询为依据，不复用生产 QuerySpec 编译器；集成测试包含会导致支付重复累计的错误 JOIN 对照。规模验证使用两个 seed，每个重复生成并校验源数据 hash，重复查询比较结果 hash，记录硬件、版本、数值与 SQL 执行计划。

当前 evidence 是计算结果的不可变快照元数据，尚无 run/evidence ID 与持久化证据注册表；那些在 M2/M3 建立。没有真实模型、工具闭环、HTTP、会话、预算状态机或完整评测完成声明。
