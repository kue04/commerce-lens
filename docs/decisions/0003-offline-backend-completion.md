# ADR 0003：无外部模型调用的后端交付

2026-10-22，已采用。用户要求继续所有不依赖真实外部 API 的后端步骤，因此补齐本地生命周期和三类经营分析、受控信号、离线评测、备份与演示材料；真实供应商评测明确延期，不能以离线规则或 faux provider 代替。此记录更新 ADR 0002 中当时尚未实现的会话删除、反馈、分页、保留清理和重试边界。

采用原 HTTP 契约的兼容扩展 v1.1.0：金额仍为分，件数为 units；原 v1.0.0 报告可读取。新业务信号用独立表和行级权限，不能因为新增表就开放自由查询；published 数据不可变，源缺失不补零。SQL 计算与有限规则生成事实和可能解释，模型只选已注册证据；不采用开放式自由文字来绕过事实校验。

评测冻结 120 案例，按 family 隔离，预期值由独立 SQL 得出；只把自然语言或攻击 body 发给被测 API。规则系统的评测和无模型本地 P95 单独报告，B/C 真实模型基线与人工复核保留 NOT_RUN，防止作品集夸大。所有版本化结果保留，性能测试中发现的 Top-N hash 缺陷用规范 JSON hash 修复并保留回归。

本地没有 pg_dump 可执行文件，因此提供固定表白名单的一致性逻辑快照：业务与应用表在同一 repeatable-read 中导出，恢复只允许已迁移的空库、核对迁移 hash 和内容 hash，重新经过发布约束，活动 run 标记 interrupted。它不是任意数据库通用备份工具，不支持将来源不明的备份当可信输入，也不覆盖现有数据库。
