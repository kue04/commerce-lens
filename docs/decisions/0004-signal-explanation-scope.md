# ADR 0004：子范围信号与解释的证据匹配

2026-10-22，已采用。保持 QuerySpec 与 HTTP 1.1.0，依据 PRD 第一部分 §7 的事实/假设边界、第三部分 §5 的信号粒度限制。

`inspect_signals` 允许缩小已确认的筛选，这是工具权限规则。合法的子范围观测并不证明较大范围的下降发生在该子范围。此前报告验证只检查“信号是合法子集”，随后把全范围比较/贡献用于生成解释，可能把增长渠道的流量下降或增长大区的零库存用于解释其他范围的经营下降。

本次采用保守匹配，不新增隐式 SQL、模型请求或查询 DTO：

- 库存解释仍需单个下降 SKU、足够覆盖、增加的零库存及 comparison/contribution/inventory 引用；库存核查的渠道/大区选择必须与 SKU 贡献相同。库存实际为大区共享池，事实文本明确不能视为渠道独享。
- 流量解释要求渠道/大区选择与比较总量相同、两期覆盖完整且归因版本匹配，仅用于支付金额/件数。SKU 不作为流量归因维度，SKU-only 子集仍只能提供渠道背景。
- 所有筛选按集合比较，顺序无意义。未筛选与显式列表暂按不同范围处理：报告生成器没有可信目录来判断显式列表是否穷尽，不以猜测放宽。
- 不匹配时保留带范围的观测事实，新增 unknown 说明解释缺口。若用户要解释该切片，应以同一 QuerySpec 创建范围明确的新分析，而不是自动把全范围数值当作切片数值。

`sameScope` 的比较/贡献权限规则与 `signalScope` 的合法子集规则不改。活动只保留时间重叠措辞；退款原因事实仍引用其自身查询范围。本次没有扩展 P1，也不修改冻结标签或已有不可变报告。

专项证据见 tests/unit/agent.test.ts、tests/integration/signal-scope.test.ts。后者真实发布合成数据：A 华东支付 1000000→1500000 分，华北 5000000→500000 分，总体 A 下降 4000000 分；只有华东 A 零库存增加，华东/tmall 流量下降。独立 SQL oracle 与手工预期一致。真实 Pi Core 用明确 faux-provider 依次查询和提交，经 HTTP 报告落库/证据读取/JSON 导出验证三种子范围不生成错误解释；相同范围的流量解释保留。此测试不是外部模型评测。
